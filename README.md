# 天光 · 城市天气对照

线上地址：**https://deskfish.github.io/tianguang-weather/**

同一时刻，横向对照北京、薛城区与更多城市的实时天气、逐时气温与未来七日预报。
纯静态单页，数据来自 Open-Meteo（CC BY 4.0）。

- 北京时间实时时钟
- 最多 6 座城市横向对照
- 24 小时气温折线 / 14 项指标对照 / 未来七日
- 地址栏 `?cities=beijing,xuecheng` 可分享城市组合
